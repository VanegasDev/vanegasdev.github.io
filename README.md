# Mario Vanegas — Portfolio

Minimal dark portfolio for GitHub Pages.

## Run locally

Open `index.html` directly in your browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a public repository named `<your-github-username>.github.io`.
2. Push the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.

## Replace before publishing

- `hello@example.com`
- LinkedIn URL
- GitHub URL
- Project case-study links
- Project copy/metrics after review
